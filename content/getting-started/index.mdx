# Installation

Requires **Python 3.11+**. No database server, no Docker, no external
service to stand up first.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

<Callout type="warning">
  On some Python builds, an editable install's `.pth` entry is silently
  skipped, and `import shipyard` fails with no explanation even though
  `pip` reported success. If that happens, this makes edits (and the
  install) work reliably:

```bash
echo "export PYTHONPATH=\"$PWD:\$PYTHONPATH\"" >> .venv/bin/activate
deactivate && source .venv/bin/activate
```
</Callout>

## Check it worked

```bash
.venv/bin/python -m pytest -q
```

This passes with no network access and no API key — nothing here talks to a
real model yet.

## What each way of using Shipyard actually needs

Not everything needs a model or a credential. Use this to know what you can
try right now versus what needs setup first:

| To do this | You need |
|---|---|
| Watch the yard dashboard, browse past runs | Nothing — reads the local run history |
| Run the free scripted demo | Nothing — no API key, no cost |
| Start a real new product (`shipyard new` / `POST /api/intake`) | Claude Code installed and authenticated (`claude` on `PATH`), or an OpenAI-compatible provider key |
| Build it (`shipyard build` / `POST /api/builds`) | Same as above, plus whatever the target topology's *own* product needs at runtime (see [Operator Secrets](/getting-started/operator-secrets)) |

Run `shipyard` with no arguments any time to see the current, complete
command list straight from the tool itself.

## Repository layout

Only relevant if you're going to read or extend Shipyard's own source, not
for using it day to day:

```
shipyard-py/
├── shipyard/        # the library: runner, gates, trace, adapters, CLI, dashboard
├── topologies/       # the product shapes Shipyard can build — see What You Can Build
├── specs/             # one spec.md + criteria.json per product you've started
├── tests/              # the test suite
└── examples/            # the free scripted demo
```
